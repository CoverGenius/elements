# CG Elements

CG Elements is a framework-agnostic SDK from Cover Genius. It renders insurance offers on partner pages as a `<cg-elements>` custom element. It works in any web app that supports `<script type="module">` and custom elements, and in mobile WebViews.

> **Alpha.** This SDK is in alpha and the API can change between versions. It is not on npm yet.

## Install

Not available yet. The package is not on npm. This section will show the install command when the first version is published.

| Package | Description |
| --- | --- |
| [`@covergenius/elements`](packages/vanilla) | The core engine. Registers `<cg-elements>`, renders offers, and emits selection events. |
