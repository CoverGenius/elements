# Security policy

## Reporting a vulnerability

Report a vulnerability privately. Open the **Security** tab of this repository and choose **Report a vulnerability**. Do not open a public issue or pull request for a security problem.

Include the package name, the version, the steps to reproduce, and the impact you expect.

## Supported versions

Only the latest release receives security fixes.

## Scope

This policy covers the packages in this repository. Report problems in the Cover Genius platform or its APIs through your Cover Genius partner contact.
